📦 What drex-decision-models Does

drex-decision-models is an open project built around decision models — structured ways of describing a choice, the options involved, and the things that matter when you compare them. Instead of keeping that reasoning in a spreadsheet, a notebook, or your head, a decision model writes it down in a clear, repeatable format.

This repository bundles three parts that work together: a small runtime that opens and evaluates the models, documentation that explains how the models are put together, and model pages that present each model in plain language. The result is a package you can pick up on a normal Windows computer and start using without a technical background.

Because the models are open, you can read them, compare them, and learn from how they are structured. Nothing is hidden behind a locked screen, and nothing asks you to sign up for an account before you can look around.

✨ What You Get

Everything below is included in the same download, so there is no second package to find and no extra setup step to remember.

  • A working runtime. A lightweight engine that opens decision models, checks that they are valid, and produces results you can read on screen.
  • Readable model pages. Each model comes with a page that explains what the decision is about, which options exist, and what the model is trying to weigh up.
  • Documentation in plain language. Written for people who want to understand a model, not only for people who want to rebuild it.
  • An open format. Models are stored as ordinary text-based files, which means they are easy to back up, share, and copy between computers.
  • Room to grow. You can add your own models next to the included ones once you are comfortable with how they look.
  • No account, no trial timer. The download is the whole thing. There is nothing to activate and nothing to renew.

🖥️ What Your Computer Needs

The requirements are modest. Almost any Windows laptop or desktop computer made in the last several years will be comfortable running the models.

  • Operating system: Windows 10 or Windows 11, 64-bit.
  • Memory: 4 GB of RAM or more. 8 GB is comfortable if you plan to open several models at once.
  • Storage: Around 200 MB of free space for the application, the included models and their pages.
  • Display: Any normal screen resolution. A larger window simply makes the model pages easier to read.
  • Internet: Needed for the download itself. After that, the models run locally on your machine.

You do not need to install any programming tools, database servers, or extra components to use the included models.

🧭 Your First Ten Minutes

The first session does not need to be complicated. A simple walk-through is enough to get a feel for the whole package.

  1. Start the runtime. Launch the application from the folder you created earlier. A window opens with a short list of the models that were included.
  2. Open the documentation. Read the introduction first. It explains the vocabulary used throughout — options, criteria, weights, and results — so nothing later feels like a surprise.
  3. Pick one model page. Choose a decision that sounds familiar, such as choosing between suppliers or prioritising tasks. The page tells you what the model is for before it shows any numbers.
  4. Change something small. Adjust a single weight or swap one option and watch how the result shifts. This is the fastest way to understand what the model is really doing.
  5. Save your work. Store your changed model in the same folder so it stays next to the original. You can always go back to the untouched version.

🗂️ How the Models Are Organised

The repository keeps things tidy by separating the three parts of the project. You do not have to memorise this, but knowing it helps when you go looking for something specific.

The runtime is the part that does the work. It reads a model, checks that it is complete, applies the logic described inside it, and produces a result. The documentation explains the rules the runtime follows and describes the format in which models are written. The model pages sit alongside the models themselves and give each one a human-friendly introduction — what problem it addresses, which inputs it expects, and how to read its output.

If you only ever use the included models, you can stay entirely on the model pages and never touch a configuration file. If you later want to build something of your own, the documentation and the existing models give you a complete worked example to copy from.

❓ Common Questions

The download did not start.

Return to the project page using the link above and try again, ideally in a fresh browser tab. Very large downloads can also be interrupted by a slow connection, so waiting a moment and retrying is usually enough.

Windows shows a protection message when I open the application.

This is standard for software that did not come from the Microsoft Store. Choose the option that keeps the file and continues, and the application will start normally.

Can I move the folder to another computer?

Yes. Because everything lives in one folder, copying that folder to another Windows machine carries the application, the models and the documentation with it.

Do I need to update anything?

When a new version is published, the project page lists it. Download the newer copy and place it in a fresh folder; your existing models can simply be copied across. Keeping the older folder until you are sure everything works is a good habit.

🤝 Getting Help and Sharing Feedback

The project is open, which means questions, ideas and corrections are welcome. If a model page is unclear, if a step in the documentation could be phrased more simply, or if you have built a model you think others would find useful, the project page is the place to say so.

When you describe a problem, mention your Windows version, which model you were working with, and what you expected to see. That small amount of detail turns a vague report into something that can actually be fixed.
